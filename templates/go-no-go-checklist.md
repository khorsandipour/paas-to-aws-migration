# GO / NO-GO checklist (template)

**Any single item below = NO-GO.**

- [ ] Unexplained loss or reversion of records
- [ ] Old password accepted after a password change
- [ ] Hash mismatch on an issued document
- [ ] A valid verification or public link is broken
- [ ] A wrong-store fallback was activated
- [ ] The authority of the source data is unclear
- [ ] Side effects were not contained during the rehearsal
- [ ] Recovery evidence failed
- [ ] Any unresolved P0 or P1 finding
- [ ] Renderer qualification failed without an approved exception
- [ ] Alarm delivery was not proven with a safe test stimulus
- [ ] The old and new systems are able to act on production at the same time
